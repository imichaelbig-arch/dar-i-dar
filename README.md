# Цветы Здесь

Создай мобильное веб-приложение (PWA) для платформы перепродажи подаренных букетов цветов. Интерфейс должен быть полностью на русском языке. 

### Визуальный стиль (Строго по референсу):
- Светлая тема с мягкими розовыми акцентами.
- Закругленные карточки, кнопки с фиолетово-синим градиентом.
- Адаптивная верстка, идеально оптимизированная под экраны смартфонов.

### Нижнее навигационное меню (Bottom Tab Bar):
1. **Цветы** (иконка букета, активная вкладка по умолчанию).
2. **Продать** (иконка знака рубля или плюса).
3. **Мой аккаунт** (иконка профиля).

### Страница 1: Лента ("Цветы")
- **Шапка:** По центру выбор города "ГОРОД: Москва" (выпадающий список), слева иконка чата, справа кнопка профиля.
- **Категории (горизонтальный скролл): ** "Все букеты", "Розы", "Цветы", "Растения". Рядом с каждым названием счетчик количества (например: 575).
- **Сортировка:** Текст "ФИЛЬТР Сортировать:" и выпадающий список (по умолчанию "Без фильтра").
- **Сетка объявлений: ** В 2 колонки. Каждая карточка содержит:
- Квадратное фото букета.
- Текстовый блок параметров:
- Размер: [Значение]
- Свежесть: [Значение]
- Цена: [Значение] руб. 
- Фиолетовую градиентную кнопку "Купить" с иконкой корзины посередине.

### Страница 2: Размещение ("Продать")
- Форма добавления нового букета.
- Поле загрузки фотографии (с возможностью сделать фото с камеры).
- Выпадающий список выбора города.
- Выпадающий список "Размер" (Огромный, Большой, Средний).
- Выпадающий список "Свежесть" (Свежайшие, Отличная, Хорошая). 
- Поле ввода цены (в рублях).
- Кнопка "Опубликовать букет".

### Логика оплаты и комиссия:
- При нажатии на кнопку "Купить" открывается симуляция экрана оплаты.
- На экране оплаты четко распиши детализацию:
- "Цена продавца: [Цена]" 
- "Сервисный сбор платформы: 200 руб." 
- "Итого к оплате: [Цена + 200] руб." 
- После нажатия "Оплатить" букет временно скрывается из общей ленты или получает статус "Продано".

### Технический стек: Используй React, Tailwind CSS и Lucide-react для иконок. Подготовь базу данных Supabase с таблицей "bouquets" (поля: id, image, size, freshness, price, city, status).
