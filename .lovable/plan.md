# Дата и время публикации букета

## Что уже есть
В таблице букетов уже есть поле времени создания записи (`created_at`), которое заполняется автоматически при публикации. Миграция базы данных не нужна — поле есть и уже приходит в ленту.

## Что добавим
В карточке букета в ленте, под ценой, появится аккуратный блок из двух строк:

```text
Дата: 03.09.2026
Время: 19:05
```

Формат строго как указано: дата — ДД.ММ.ГГГГ, время — ЧЧ:ММ (24 часа), по московскому времени.

## Технические детали
- Небольшой помощник форматирования (в `src/lib/`): из `created_at` возвращает `{ date, time }` через `Intl.DateTimeFormat` с `timeZone: "Europe/Moscow"`, двузначными днём/месяцем/часом/минутой и 4-значным годом.
- `src/routes/index.tsx`: в `BouquetCard` после строки «Цена» добавить две строки в том же стиле (подпись серым, значение — обычным текстом), с `<time dateTime={bouquet.created_at}>`.
- Тип `Bouquet` в этом файле дополнить полем `created_at: string` (запрос уже делает `select("*")`).
- Стилистика существующая: `text-[13px]`, `text-muted-foreground` для подписей — новые цвета и шрифты не вводим.
